# Modelos IA offline

Aquí debe colocarse el modelo ONNX musical elegido, su versión, licencia,
hash SHA-256, etiquetas y configuración de preprocesamiento. El proyecto no
incluye un modelo de clasificación porque debe validarse su licencia y
compatibilidad antes de distribuirlo. Sin modelo, las pistas quedan POR
CLASIFICAR; la aplicación no inventa predicciones.
